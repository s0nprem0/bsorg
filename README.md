# BetterOSAS

A personal project initiative aimed at creating a streamlined, modern, and highly usable directory for student leadership enthusiasts and the wider student body.

## Why Build This Project?

The current [official CvSU student organizations page](https://cvsu.edu.ph/student-organizations) has several usability issues:

- Heavy text-dense layout with poor visual hierarchy
- No effective search or filtering system
- No direct links to social media, email, or contact channels
- Poor mobile experience
- Outdated information due to static nature


**BetterOSAS** aims to bridge this gap by transforming a rigid, administrative directory into an interactive, mobile-first ecosystem built specifically for student discovery and community engagement.

## Core Features

* **Bento Grid & Card UI:** Organizations are displayed as modern, responsive cards complete with official logos, clear tag systems, and aesthetic visual anchors.
* **Multi-Faceted Live Filtering:** Instant client-side filtering by **Category**, **College**, and **Campus** to ensure smaller or newer organizations aren't buried under text.
* **Actionable Profiles (CTAs):** A dedicated view for each organization that acts as a bridge, housing direct "Join Now" application forms and official social links.
* **Validation Badges:** A dynamic tag indicating whether an organization's records have been verified or updated for the current semester.
* **Mobile-First Responsiveness:** A highly accessible UI designed from the ground up for quick, seamless viewing on smartphones.

## Data Source
Organization data is compiled from publicly available information on the CvSU website and related Facebook pages.

This project is **not scraping in real-time**. It uses manually maintained static data.
